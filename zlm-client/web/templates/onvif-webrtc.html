怎么用

  1. 看直播到「直播管理」打开流，点 WebRTC。播放地址是 /index/api/webrtc?app=应用&stream=流名&type=play，不要填进下面的表单。
  2. Rooms本页 Rooms 是会议房间列表，不是直播列表。没有会议时为空是正常的。
  3. RoomKeeper只对接外部 WebRTC 信令服务器。没有外部房间就不用添加。
  4. Proxy PlayerKey 是代理播放器内部 key，用来查 ICE / 传输详情，不是播放 URL。
  5. 信令边界WHIP / WHEP / webrtc 是信令端点，必须用对应 HTTP 方法，不能当普通视频地址。
