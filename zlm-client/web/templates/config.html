录制 / HLS 切片落盘 运维台

多数场景关掉虚拟主机，磁盘上就只有 live/ 和 mp4/，不会出现 __defaultVhost__。live/{app}/{stream}/ 是给播放器用的滚动切片（查问题可短时回看，到期自动清）；文件页「开始录制」才是正式录像，写在 mp4/，不会跟着清。dash/flv/hls/rec/ts 是空壳，启动时会删。定时截图由运维台 Go 服务读取在线流并调用 FFmpeg 归档；ZLM 自带 getSnap 只是按需 API，缓存目录是 md5(url)，不能改成按流名归档。

高级操作

服务重启、受限目录删除和模板化广播；全部需要二次确认并写入审计。不开放任意文件/二进制下载（downloadFile / downloadBin）。

重启 MediaServer

仅重启当前节点 ZLM 进程。Windows 会拉起同名进程；非 Daemon 模式可能直接退出。不会通过通用 API 透传。

删除受限录像目录

只允许删除默认录像根下某一天（YYYY-MM-DD）的目录或其中单个 mp4，不能指定 customized_path。

删除受限截图目录

只删除 ZLM snapRoot 下该流的 jpg；填写文件名则只删单个文件，留空则删该流截图目录。

模板化广播

向指定流的播放端发送预设文本。notice 仅允许 1-200 字纯文本，禁止 HTML。

getServerConfig 全量；保存前校验，通过后 setServerConfig 即时生效
