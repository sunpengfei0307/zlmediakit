录制 / HLS 切片落盘 运维台

多数场景关掉虚拟主机，磁盘上就只有 live/ 和 mp4/，不会出现 __defaultVhost__。live/{app}/{stream}/ 是给播放器用的滚动切片（查问题可短时回看，到期自动清）；文件页「开始录制」才是正式录像，写在 mp4/，不会跟着清。dash/flv/hls/rec/ts 是空壳，启动时会删。定时截图由运维台 Go 服务读取在线流并调用 FFmpeg 归档；ZLM 自带 getSnap 只是按需 API，缓存目录是 md5(url)，不能改成按流名归档。

DASH 转封装 运维台

ffmpeg 拉本机 RTMP，MPD 写到 /data/zlm/{app}/{stream}/dash.mpd（与 8090 路径一致）

高级操作

服务重启和受限目录删除；全部需要二次确认并写入审计。不开放任意文件/二进制下载（downloadFile / downloadBin）。

重启 MediaServer

仅重启当前节点 ZLM 进程。Windows 会拉起同名进程；非 Daemon 模式可能直接退出。不会通过通用 API 透传。

删除受限录像目录

按录制管理实际目录删除：mp4/record/{app}/{stream}。日期留空则删除该流全部录像（含子目录）；填写 YYYY-MM-DD 只删当天；可选再填单个 mp4 文件名。

删除受限截图目录

按录制管理实际目录删除：snap/{stream}。留空文件名则删除该流全部截图；填写则只删单个 jpg。
